# 虚拟校园项目 · 总文档（Phase 1 复刻）

> 这是「复刻 peteroravec.com」这件事的**唯一文档家**。骨架按《文档框架-协作设计》的 3 层来，细节参照旧仓库 `虚拟校园项目重构`。
> 一句话：**人看 1 层（理解），接口看 2 层（暗号），AI 看 3 层（执行）。**

---

## 这栋文档楼长什么样

| 层 | 装什么 | 谁看 | 一句话 |
|---|---|---|---|
| `01-理解层/` | 每个系统一张卡，讲"是什么、怎么动、为什么"；**按串/并行分成 5 个抽屉**（地图线 / 玩法线 / 内容线 / 独立件 / 旁支） | 你 | 判断 + 学习 |
| `02-暗号层/` | 系统之间的接头约定 | 你俩 + AI | 握手暗号 |
| `03-执行层/` | AI 的精确细节（指路到旧仓库） | AI | 逆向 + 实现 |
| `04-内容层/` | 作品集的文案内容 | 你 | 剧本 / 简介 |
| `05-素材/` | 原站证据（指路到旧仓库 sample） | 你 + AI | 一手材料 |

顶层还有 3 份"唯一事实源"：

- `计划表.md` —— 所有"天天变"的东西（状态 / 卡点 / 下一步）只写这
- `术语表.md` —— 所有"叫法"统一在这
- `决策记录.md` —— 所有"取舍 + 为什么"记在这

---

## 怎么读（新手顺序）

1. 先读 `01-理解层/00-系统地图.md` —— 一眼看全这栋楼分几块
2. 挑一张感兴趣的系统卡（建议从 `01-地图线/04-地图分块.md` 开始，它是唯一做完的示范）
3. 想知道"谁和谁握手" → 翻 `02-暗号层/接头暗号表.md`
4. 想知道"现在到哪了" → 翻 `计划表.md`
5. 想看 AI 的精确细节 → 顺 `03-执行层/` 的链接进旧仓库

---

## 铁规矩（摘自《文档框架-协作设计》）

1. **文档先行**：理解卡没写明白，不许写代码。
2. **唯一事实源**：每个事实只住一个地方，别处"指路不复制"。写之前先问一句"这个事实的家在哪？"
3. **变 / 不变分离**：不变的散在 3 层，变的（状态 / 卡点 / 下一步）只进 `计划表.md`。
4. **歧义能留在"为什么"，不能留在"接口"**。
5. **你负责懂，AI 负责准**：你看懂全局、拍板对错；AI 翻译成精确契约、写代码。
