# 原站有哪些功能（能力清单）

> **一句话：这是一张功能清单，记录原站看得到的能力和我们对它们的了解程度。**

本清单只记录用户或浏览器可以观察到的能力，不在这里决定代码实现。

| ID                | 区域  | 原站能力或行为                 | 当前证据                          | 状态           | 优先级 |
| ----------------- | --- | ----------------------- | ----------------------------- | ------------ | --- |
| CAP-WEB-001       | 网站  | 加载并展示原站首页内容             | 根 HTML、CSS、Angular Bundle     | `partial`    | P1  |
| CAP-WEB-002       | 网站  | 展示作品、卡牌和弹窗内容            | HTML、图片、Bundle                | `partial`    | P1  |
| CAP-GAME-001      | 游戏  | 页面出现游戏 Canvas 和 Play 入口 | 浏览器运行时采集                      | `confirmed`  | P0  |
| CAP-GAME-002      | 游戏  | 点击 Play 进入 Playing 状态   | CDP 实际点击结果                    | `confirmed`  | P0  |
| CAP-ASSET-001     | 资源  | 启动时加载地图、角色和环境资源         | Network、Bundle Loader 常量      | `confirmed`  | P0  |
| CAP-MAP-001       | 地图  | 使用主索引和多个地图分块            | master.json、chunk0~24、Network | `confirmed`  | P0  |
| CAP-LAYER-001     | 地图  | 世界包含碰撞、脚步和粒子等图层数据       | walls、footsteps、particle JSON | `confirmed`  | P0  |
| CAP-PLAYER-001    | 玩家  | 玩家可接收方向输入并移动            | 浏览器运行、现有复刻对照                  | `partial`    | P0  |
| CAP-COLLISION-001 | 玩家  | 移动受到地图碰撞规则限制            | 地图数据、运行表现待细核                  | `partial`    | P0  |
| CAP-CAMERA-001    | 相机  | 视口随玩家在世界中变化             | 浏览器运行表现                       | `partial`    | P0  |
| CAP-NPC-001       | 实体  | 原站包含多种 NPC 与环境实体        | Bundle Loader、精灵资源            | `partial`    | P1  |
| CAP-ROUTE-001     | 车辆  | 原站包含车辆、火车和路线相关表现        | Bundle、车辆资源                   | `discovered` | P1  |
| CAP-ZONE-001      | 交互  | 特定区域可能触发角色或场景变化         | Bundle 线索、待运行核验               | `discovered` | P1  |
| CAP-FX-001        | 动效  | 原站包含粒子、烟雾、天气等表现资源       | Bundle、粒子数据、精灵资源              | `partial`    | P2  |

## 状态说明

```text
discovered  只发现名称或线索
partial     已有部分证据，机制未完全弄清
confirmed   关键可观察行为已有充分证据
```

## 添加规则

新增条目必须包含可定位证据；没有证据的未来设想写入 [[../05-还不清楚什么/还缺哪些答案（未知问题队列）]]，不加入本清单。
