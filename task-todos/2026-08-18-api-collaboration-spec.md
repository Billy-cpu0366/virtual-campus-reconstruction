## 已确认的项目事实

- 当前项目有 16 个系统；地图线和玩法线 8 个系统均已完成确定性纯逻辑 CORE，但 Phaser/Vite、网络、缓存、真实 Tilemap/渲染和运行集成仍未完成。
- L1 接口索引的当前路径是 `02-接口层/API契约表.md`；`02-暗号层` 已退役。
- L2 精确事实应回到对应 `03-执行层/`系统卡 §5 和代码类型，不能在协作规范中另建平行真相。
- `createWorld` / `destroyWorld` 的上层 Caller、`startFollow` 的准确调用表达，以及“这格能走吗”对玩家物理碰撞与 NPC 寻路的拆分仍需在冻结前确认。
- 玩家动态深度 `500 + y * 0.1` 是 SYS-LAYER 的共享规则，由 SYS-PLAYER 消费，不应误写成独立跨系统函数调用。
- 内容线和世界内容线多数仍是 `undesign`；后续接口链只能标为候选或 Draft。
