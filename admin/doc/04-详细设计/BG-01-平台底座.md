## 一、`/login` 登录页

### 1.1 布局

页面居中，一张白卡片，最大宽度约 24rem。卡片内从上到下：标题、邮箱、密码、错误提示（有才显示）、登录按钮。

### 1.2 元素

| 元素 | 类型 | 标签 / 占位 | 必填 | 说明 |
|---|---|---|---|---|
| 标题 | 文本 | 登录后台 | — | `text-2xl font-semibold` |
| 邮箱 | `input[type=email]` | 邮箱 | 是 | `autoComplete=username`；提交前转小写、去空格 |
| 密码 | `input[type=password]` | 密码 | 是 | `autoComplete=current-password` |
| 错误提示 | 文本 | — | — | 红色，只在失败时出现 |
| 登录按钮 | `button[type=submit]` | 登录 / 登录中… | — | 提交中禁用 |

### 1.3 状态

| 状态 | 界面 | 触发 |
|---|---|---|
| 初始 | 空表单，按钮可点 | 打开页面 |
| 提交中 | 按钮禁用，文案"登录中…" | 点登录 |
| 失败 | 红色提示，按钮恢复 | 凭据错误、账号停用、网络失败 |
| 成功 | 跳 `/admin` | 会话签发成功 |

### 1.4 事件

| 事件ID | 触发 | 前置 | 后续动作 | 失败处理 |
|---|---|---|---|---|
| E-BG01-01 | 点"登录" | 表单已填 | 阻止默认提交，进入提交中 | 浏览器必填校验兜底 |
| E-BG01-02 | 凭据正确 | 提交中 | 跳 `/admin`；服务端写 `login/success` 审计 | 跳转失败显示错误 |
| E-BG01-03 | 凭据错误 / 账号停用 | 提交中 | 显示"邮箱或密码不正确"；服务端写 `login/failed` 审计 | 不暴露具体原因 |
| E-BG01-15 | 审计写失败 | E-BG01-02/03 | 登录结果不变；服务端错误日志记录 | 前端不提示 |

### 1.5 调用

- `signIn("credentials", { email, password, redirect: false, redirectTo: "/admin" })`。
- 返回 `error` 时统一提示；抛异常时提示"网络异常，请稍后重试"。
- 成功后 `window.location.assign("/admin")`，让服务端重新取会话。

### 1.6 样式与可用性

- 卡片：`max-w-sm rounded-2xl bg-white p-8 shadow-sm`。
- 输入框：`mt-1 w-full rounded border p-2`；标签 `mb-4 block text-sm`。
- 按钮：`w-full rounded bg-blue-700 p-2 text-white`；禁用时 `opacity-50`。
- 错误：`text-sm text-red-700`。
- 所有输入有可见标签；Tab 顺序：邮箱 → 密码 → 登录。

## 四、`/admin/audit` 操作审计

### 4.1 筛选项

| 元素 | 类型 | 说明 |
|---|---|---|
| 校园 | 文本框 | 按集名精确匹配；空表示全部 |
| 动作 | 下拉 | 全部、login、logout、create-campus、save-draft、validate、preview、publish、rollback |
| 总数 | 文本 | "共 N 条" |

筛选变化时回到第 1 页。

### 4.2 表格列

| 列 | 格式 | 说明 |
|---|---|---|
| 时间 | `zh-CN` 本地时间 | 精确到秒 |
| 操作者 | 邮箱；没有显示"—" | 现状显示 `userId`，本轮改成邮箱 |
| 动作 | 动作名 | 可加中文标签，但保留原值 |
| 校园 | 集名或"—" | 等宽字体 |
| 文件 | 相对路径或"—" | 过长省略，悬停看全文 |
| 前哈希 | 前 12 位或"—" | 等宽字体 |
| 后哈希 | 前 12 位或"—" | 等宽字体 |
| IP | 文本或"—" | 等宽字体 |
| 详情 | 折叠行 | 点行展开 `detail` 和 User-Agent（建议新增） |

### 4.3 分页

- 每页 25 条，第一圈不做每页条数切换。
- "上一页 / 下一页"按钮；首页禁用上一页，末页禁用下一页。
- 显示"第 N 页"和"共 M 条"。
- 筛选变化时 `page` 重置为 1。

### 4.4 状态

| 状态 | 表现 |
|---|---|
| 加载中 | 表格区域显示"加载中…"，筛选仍可用 |
| 空 | "暂无记录" |
| 失败 | "加载失败，请重试"+ 重试按钮（现状缺失，本轮补） |
| 未登录 | 接口 401，跳登录页 |

### 4.5 事件

| 事件ID | 触发 | 后续动作 | 失败处理 |
|---|---|---|---|
| E-BG01-06 | 打开审计页 | 请求第 1 页 | 显示失败状态 |
| E-BG01-10 | 改校园筛选 | 重置到第 1 页并请求 | 保留旧数据，显示错误 |
| E-BG01-11 | 改动作筛选 | 同上 | 同上 |
| E-BG01-12 | 翻页 | 请求目标页 | 同上 |
| E-BG01-13 | 点行展开 | 显示 `detail` / User-Agent | — |
| E-BG01-14 | 审计请求返回 401 | 跳 `/login?next=/admin/audit` | — |

### 4.6 接口

`GET /api/admin/audit?page=&limit=25&campus=&action=`

响应里的 `items[].userId` 旁增加 `userEmail`（服务端按 `userId` 批量查 `AdminUser`），避免页面显示一串 cuid。`userEmail` 查不到时回退显示 `userId`。

## 八、状态管理约定

所有异步区块必须四态齐全：

| 状态 | 必备表现 |
|---|---|
| 加载中 | 明确文案或骨架，不能空白 |
| 成功 | 正常内容 |
| 空 | "暂无记录 / 暂无数据"，不是空白 |
| 失败 | 中文错误 + 重试入口 |

补充规矩：

- 禁止 `catch {}` 静默吞错；至少 `console.error` 并给用户提示。
- 提交类按钮在请求期间禁用，防止重复提交。
- 接口 401 统一跳登录页，并带 `next=<当前路径>`；登录成功后回原页（第一圈可先回 `/admin`，`next` 作为待办）。
- 筛选变化重置分页；分页请求失败保留上一页数据并提示。

## 十一、异常与边界

| 情况 | 处理 |
|---|---|
| 登录时网络断开 | 提示"网络异常，请稍后重试"，按钮恢复 |
| 会话在页面内过期 | 接口 401 → 跳登录页；不清空用户正在填的表单（第一圈先不做草稿保存） |
| 停用账号仍持有旧会话 | Q5 确认后，下次请求踢回登录页 |
| 审计写失败 | 登录不阻断，服务端日志；业务写操作失败 |
| 审计查询失败 | 页面显示错误和重试，不白屏 |
| 时间显示 | 统一 `zh-CN` 本地时间；数据库存 UTC |
| 反向代理 | 取 `x-forwarded-for` 第一段；同源校验读 `X-Forwarded-Host` 优先 |
