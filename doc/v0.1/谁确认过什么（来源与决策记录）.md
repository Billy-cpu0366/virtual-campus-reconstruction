## 1. 状态口径

| 维度 | 可用值 | 说明 |

| 内容性质 | `requirement / suggestion / example` | 原始材料属于什么 |
| 决策状态 | `proposed / accepted / rejected / superseded / not-applicable` | Human 如何处理决定 |
| 持久化状态 | `pending / persisted` | 是否进入权威位置和 AI 必读链 |

| 文件同步 | `pending / updated / verified` | 单个受影响文件的迁移进度 |
