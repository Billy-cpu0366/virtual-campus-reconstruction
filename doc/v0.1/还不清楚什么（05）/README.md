# 还不清楚什么（05）

> **说人话：把暂时答不上来的问题摆出来，说明为什么重要、下一步怎么查，防止猜测被当成事实。**
>
> 这里不是失败清单，而是项目明确知道“还没有证据”的地方。

本目录管理尚未弄清楚的问题，不存放正式设计结论。

## 文档

- [[未知问题队列]]

## 问题闭环

```text
发现问题
→ 记录为什么重要和需要什么证据
→ 针对性调查
→ 将完整结论写入唯一正式主定义
→ 更新差距矩阵
→ 在队列保留关闭摘要和主定义链接
```

禁止根据文件名猜测路径或把假设直接写成原站事实。关闭记录只保留审计摘要、证据定位、正式主定义链接和残余未知；不得继续作为完整设计结论的第二所有者。
