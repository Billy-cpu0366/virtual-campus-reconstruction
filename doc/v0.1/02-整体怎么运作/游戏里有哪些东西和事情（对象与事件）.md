# 游戏里有哪些东西和事情（对象与事件）

> **一句话：这份文件列出游戏里的角色、地图等东西，以及点击、进入区域等会发生的事情。**

## 1. 当前识别的主要对象

| 对象 | 说人话解释 | 主要管理系统 | 状态 |
|---|---|---|---|
| 页面应用 | 承载内容和游戏入口的网页 | 应用启动与页面状态 | partial |
| 游戏 | Phaser 运行实例 | 游戏生命周期 | partial |
| 地图 | 整个可移动世界的数据 | 世界与地图 | confirmed |
| 地图分块 | 世界的一部分地图数据 | 地图分块 | confirmed |
| 图层 | 地面、碰撞、前景等地图层 | 图层与遮挡 | partial |
| 玩家 | 用户控制的角色 | 玩家、移动、输入 | partial |
| NPC | 非玩家角色 | NPC与环境实体 | discovered |
| 车辆/火车 | 沿世界路线运动的实体 | 车辆与路线 | discovered |
| 区域 | 可触发语义或行为的空间 | 区域触发 | discovered |
| 可交互对象 | 能被玩家触发的对象 | 世界交互 | discovered |

## 2. 当前识别的主要事件

| 事件 | 触发者 | 可能参与的系统 | 状态 |
|---|---|---|---|
| 页面启动 | 浏览器 | 页面状态、资源加载 | partial |
| 点击 Play | 用户 | 页面状态、游戏生命周期 | confirmed |
| 资源加载完成 | 资源加载器 | 游戏生命周期、世界 | partial |
| 玩家生成 | 世界/场景 | 玩家、地图、相机 | discovered |
| 玩家开始/停止移动 | 输入 | 输入、玩家、移动 | partial |
| 发生碰撞 | 玩家与世界 | 移动、碰撞、地图 | discovered |
| 进入/离开区域 | 玩家位置变化 | 区域、交互、UI | discovered |
| 车辆到达路线节点 | 车辆移动 | 路线、车辆、动效 | discovered |

## 3. 主要关系

```text
输入产生移动意图
→ 玩家/移动系统处理
→ 地图碰撞限制结果
→ 玩家位置更新
→ 相机跟随
→ 区域系统判断是否触发事件
```
