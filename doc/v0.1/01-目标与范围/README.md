# 01-目标与范围

> **说人话：我们究竟要做一个什么东西，做到什么程度才算完成。**
>
> 先看这里，避免把“想做的未来校园”与“当前要复刻的原站”混在一起。

本目录只回答：原站有什么、为什么复刻、当前复刻什么、做到什么程度算完成。

不在这里写类、函数、目录结构或具体技术实现。

## 文档

- [[这次要复刻什么（目标与范围）]]
- [[原站有哪些功能（能力清单）]]

## 更新规则

- 新发现原站行为：先加入能力清单并附证据。
- 范围发生变化：先修改目标与范围，再调整后续设计。
- 技术实现结论：写入概要或详细设计，不写在这里。
