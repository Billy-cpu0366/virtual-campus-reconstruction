## 7. 复验步骤

### 静态与构建

```bash
npm ci
npm run typecheck
npm run smoke
node scripts/m3-01-map-contract.mjs
npm run build
```

### 手工浏览器

1. 运行 `npm run dev`；
2. 主页面等待Play，分别检查1920×1080与390×844；
3. 点击Play，确认HUD和Canvas；
4. 打开 `/sandbox.html?mode=camera` 检查移动和相机；
5. 打开 `/sandbox.html?mode=collision&spawn=1128,1928` 检查向下阻挡和向上离开；
6. 打开 `/sandbox.html?mode=camera&edge=right` 检查相机右边界；
7. 记录console、Runtime exception与HTTP失败。

本轮自动浏览器检查使用一次性CDP脚本，脚本和截图保存在系统临时目录，未作为项目工具提交。若后续需要持续回归，应在正式代码阶段根据触发规则决定是否建立稳定测试工具。
