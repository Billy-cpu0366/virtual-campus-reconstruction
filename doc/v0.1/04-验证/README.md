# 04-验证

本目录回答：结论的证据在哪里，当前复刻与原站是否一致。

## 文档

- [[原站行为基准]]：记录原站可重复观察的标准行为。
- [[现有复刻行为基线]]：记录旧 Phaser 工程在指定提交上的可重复结果，不代表原站或新工程已完成。
- [[证据追踪与实现差距]]：串联证据、系统文档、现有代码和差距。

## 验证原则

- 可观察行为优先于主观印象。
- 每条差异都要能追溯到操作步骤或文件证据。
- 没有证据的判断标为 `UNKNOWN`，不能强行通过。
