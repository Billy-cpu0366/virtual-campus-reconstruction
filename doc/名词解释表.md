# 名词解释表（全项目专有名词速查）

> **目的**：从理解层、执行层、接口层、内容层全部文档中抽出所有专有名词，一处解释、别处直接用。按 API 文档风格组织——每个名词有英文原文、中文译名、一句话定义和所在的系统上下文。
