# 虚拟校园项目重构

> Phase 1：基于 Peter Oravec 公开前端恢复系统知识，并以原站复刻验证理解。

这是当前项目的**唯一 Git 仓库和总入口**。Human 从人话层理解与决策，AI 从机器入口读取精确工程文档；证据、代码、测试和状态都在同一仓库内保持可追溯。

2. [`01-理解层/01-地图线/04-地图分块.md`](01-理解层/01-地图线/04-地图分块.md)：查看第一份完成范例；

4. [`计划表.md`](计划表.md)：用人话理解动态状态，并链接到机器权威；
5. [`04-内容层/作品集内容.md`](04-内容层/作品集内容.md)：查看Phase 1作品集内容。

### AI 执行

1. [`AGENTS.md`](AGENTS.md)：机器启动协议；

4. [`03-执行层/README.md`](03-执行层/README.md)：人话层到精确工程区的指路页。

## 仓库结构

```text
01-理解层/       Human系统理解卡、系统地图和人话进度入口
02-暗号层/       系统之间的接头语义与待确认项
03-执行层/       指向精确文档、证据、代码和任务状态
04-内容层/       Phase 1作品集内容
05-素材/         指向原站公开证据和历史资源清单

计划表.md        Human动态状态入口；不复制机器状态
术语表.md        人话术语与稳定ID说明
决策记录.md      Human决策摘要；机器台账另有唯一权威

doc/v0.1/        当前版本唯一权威工程文档
sample/           原站公开证据、运行记录、分析与采集工具
src/              正式重构源码；当前已有SYS-CHUNK确定性CORE
tests/            自动化测试
```

## Human与AI怎样接力

```text
Human看懂系统并提出目标
→ 02-暗号层说明系统之间交换什么
→ AI在doc/v0.1与sample中调查、设计和保留UNKNOWN
→ Human确认范围与验收标准
→ task_plan和决策台账记录授权
→ AI实现并运行测试/行为验证
→ 已确认结论回到理解层，精确细节继续留在工程区
```

没有Human授权，不写超出当前工作项范围的正式代码。原站事实、推断、我们的决定和未知项继续分别使用`FACT / INFERRED / DECISION / UNKNOWN`。

- **当前范围**：只做Phase 1原站逆向与复刻；Phase 2虚拟校园平台以后单独立项。
- **当前动态状态**：只看[`task_plan.md`](task_plan.md)，本README不复制。
- **旧Phaser复刻实现**：保持在外部原位置，仅在工作项明确授权时读取或修改。
- **历史规划与旧楼教程**：位于[`../虚拟校园项目/`](../虚拟校园项目/)，已经降级为历史/未来材料，不是当前事实源。
- **原总文档目录**：迁移验证期间继续保留；删除或清理需要Human再次确认。
