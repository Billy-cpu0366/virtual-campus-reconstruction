# 接头暗号表（系统之间的握手约定）

> **两个系统"握手"的暗号，全部写在这。** 框先定死，细节后补；对好暗号，两个人背对背干活也不乱。
> 铁规矩：**歧义不能留在接口里**——这里每一条都要精确。

## 一、已定死的接头

| 谁 → 谁 | 暗号（约定） | 状态 |
|---|---|---|
| 地图 → 所有人 | 地图 = 5×5 块，每块 28×28 格；块编号 `index = y*5 + x`；文件名 `chunk-{index}.json`；世界 140×140 格 × 16px = 2240×2240 px | ✅ 已定死 |
| 移动 → 地图 | "这格能走吗"：输入 (x, y) → 输出 true / false；玩家撞墙靠物理引擎，NPC 寻路靠离线 `walls-layer.json` 网格 | ✅ 已定死 |
| 分块 → 世界 | 放块 / 撤块：`applyChunk(coord, validatedChunk)` / `removeChunk(coord)` | ✅ 已定死 |
| 世界 → 所有人 | 建世界 / 拆世界：`createWorld` / `destroyWorld` | ✅ 已定死 |
| 输入 → 移动/玩家 | 三输入（键盘 / WASD / 摇杆）归一化成 8 方向；速度单轴 150 / 对角 106 | ✅ 已定死 |
| 玩家 → 相机 | 玩家世界位置 (x, y) 供 `startFollow(player, true, 1, 1)`（硬跟随 lerp=1） | ✅ 已定死 |
| 玩家 → 图层 | 动态深度 `500 + y*0.1`（桥上 1650 等为显式覆盖） | ✅ 已定死 |
| 相机 → 分块 | 相机可见范围（scrollX/Y / width / height / zoom）+1 块边距 → `loadChunksForCamera`；开场 `preloadChunksForCameraSequence` 额外 +2 边距 | ✅ 已定死 |
| 资源 → 各系统 | 两套机制并存：Phaser Loader 拉地图 JSON + 瓦片集；HttpClient 拉 `master.json` + `chunk{index}.json`（原站失败只 console.error，无重试） | ✅ 已定死 |
