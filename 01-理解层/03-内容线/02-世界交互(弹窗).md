# 世界交互·弹窗（SYS-INTERACT）

> 📌 进度：🔍 刚发现 —— 10 个模态内容还全空

## 它是什么

弹窗 / 模态窗口。玩家走进建筑、点标记，就弹出内容窗口。这是"RPG 游戏 + 信息展示"的结合点，也是复刻的核心价值所在。

## 它管哪些事

- 打开 / 关闭模态窗口
- backdrop（半透明遮罩）
- 打开时暂停游戏，关闭后恢复
- 三种关闭方式：关闭按钮 / ESC / 点 backdrop

## 走一遍

玩家走到建筑旁触发 → 模态窗口弹出（带 backdrop）→ 游戏暂停 → 玩家看内容 → 按 ESC 或点 × 或点遮罩 → 关闭 → 游戏恢复。

## 为什么这么设计

原站把"个人作品集"塞进游戏里，靠的就是这 10 个模态窗口。模态打开时暂停游戏，避免玩家在"看内容"时角色乱走。**模态 = 游戏引擎和网页 DOM 的桥梁**。

## 跟谁接口

- 出 → 游戏 UI / 内容层：展示对应的内容（作品集文案）
- 入 ← 区域触发：触发信号

> 精确约定见 `../../02-接口层/API契约表.md`

## 容易踩的坑

- **弹窗恢复时机**：关闭后什么时候恢复游戏，早 / 晚都别扭
- **焦点管理**：打开弹窗时焦点要移到弹窗上，关闭后还给游戏

## 我要学什么

"**游戏内嵌信息展示**"——这是复刻最有价值的一环，也是将来"虚拟校园平台"里"走进图书馆弹信息"的原型。
