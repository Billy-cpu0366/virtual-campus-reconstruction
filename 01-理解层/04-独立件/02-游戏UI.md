# 游戏 UI（SYS-GAME-UI）

> 📌 进度：🟡 懂一半 —— loading / Play 界面

## 它是什么

加载界面、Play 按钮、横屏提示、触摸提示浮标——游戏外面的"外壳 UI"。

## 它管哪些事

- Loading 覆盖层（白底 + 文字 + 进度条 + GIF）
- Play 界面（Logo + Play 按钮 + LinkedIn 入口）
- 横屏提示（竖屏时提示"旋转设备"）
- 触摸提示浮标（浮动手指，提示可点击）

## 走一遍

打开网站 → "Loading..." 覆盖层 + 进度条 → 加载完出现 Play 界面 → 点 Play 进入游戏 → 移动端竖屏时弹"旋转设备"提示 → 地图上浮动手指提示"这里能点"。

## 为什么这么设计

DOM UI（网页元素）和 Canvas（游戏画布）是两层。游戏 UI 用 DOM 做（HTML/CSS），游戏画面用 Canvas 做，两者分层叠加。这样加载界面、按钮能用网页那套样式（NES.css），游戏画面用 Phaser 渲染。

## 跟谁接头

- 出 → 用户：提供界面
- 入 ← 游戏状态：根据状态切换界面（加载中 / 可玩 / 横屏提示）

> 精确约定见 `../../02-暗号层/接头暗号表.md`

## 容易踩的坑

- **DOM 层和 Canvas 层的 z-index**：谁盖谁，叠错了按钮点不到、游戏看不到
- 像素字体加载 FOUT（字体没加载完先显示默认字体的闪烁）

## 我要学什么

"**DOM 层 + Canvas 层分层**"——网页 UI 和游戏画面怎么配合。这是 Phaser 项目的基本功。
