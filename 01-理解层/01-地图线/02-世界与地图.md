# 世界与地图（SYS-WORLD）

> 📌 进度：📐 图纸画好 —— 等资源那环通了就动工

## 它是什么

把整张地图"建起来"和"拆掉"的**总管**。分块、图层、碰撞这些，都挂在它下面。别人要用地图，只找它，不碰细节。

## 它管哪些事

- `createWorld`：把整个世界建起来
- `applyChunk`：往世界里放一块地图
- `removeChunk`：从世界里撤一块地图
- `destroyWorld`：把整个世界拆干净

## 走一遍

进游戏 → 世界总管把世界建好 → 分块系统一块块往里放 → 玩家在其中走动 → 退出/重开时，整个世界拆干净，不留垃圾。

## 为什么这么设计

地图太复杂（24 层、140×140 格、分块、碰撞），必须有一个"总管"统一建 / 拆。别人（玩家、NPC）只关心"世界已经建好、能用了"，不关心怎么建的。

## 跟谁接口

- 出 → 分块 / 图层：提供"放块、撤块、建层"的接口
- 入 ← 玩家 / NPC：进游戏时"世界已经就绪"

> 精确约定见 `../../02-接口层/API契约表.md`

## 容易踩的坑

- **建拆顺序**：先建谁、后建谁，错了会互相依赖不到
- **拆不干净**：卸载时没清干净，内存泄漏，越玩越卡

## 我要学什么

"**装配器 / 总管**"模式——把复杂的东西交给一个总管统一建和拆，别人只用一个简单接口。这个思路做多地图切换时特别有用。
