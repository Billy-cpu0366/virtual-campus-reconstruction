# 图层与遮挡（SYS-LAYER）

> 📌 进度：📐 图纸画好 —— 24 层已查清，5 场景证据实拍通过（仅粒子链仍开 Q-LAYER-002）

## 它是什么

24 层图层怎么叠、怎么显示、怎么清理。管的是"屋顶挡不挡人、桥怎么上下切换、脚印怎么出现"这类**遮挡关系**。

## 它管哪些事

- 地面层 / 建筑层 / 屋顶层 / 桥梁层 / 汽车层 / 墙壁层 / 粒子层 / 足迹层 的显示与清理
- 玩家走进建筑 → 屋顶层隐藏（露出室内）；走开 → 恢复
- 玩家上桥 → 桥切换上半层 / 下半层

## 走一遍

玩家走近一栋建筑 → 图层系统发现玩家在"屋顶下面" → 把屋顶层变透明，露出室内 → 玩家走远 → 屋顶恢复。玩家上桥 → 桥的上半层 / 下半层切换，让人看起来"从桥下过"还是"从桥上过"。

## 为什么这么设计

2D 俯视游戏没有真 3D，用"**图层叠加 + 隐藏**"来伪造 3D 遮挡关系。这是像素 RPG 的经典技法：谁在下面、谁在上面，靠图层顺序和"该不该显示"决定。

## 跟谁接口

- 出 → 渲染：告诉它哪些层显示、哪些层清理
- 入 ← 玩家位置：根据玩家站在哪，判断该隐藏哪层

> 精确约定见 `../../02-接口层/API契约表.md`

## 我要学什么

"**用图层叠加伪造 3D**"的思路，是 2D 游戏做遮挡的标准答案，值得记牢。
