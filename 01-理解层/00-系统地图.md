# 系统地图（复刻这栋楼分几块）

> 把 peteroravec.com 这个游戏，拆成 16 个系统。拆的依据 = **解耦 + 复用 + 顺序**（见《文档框架-协作设计》）。
> 先看这张图，再挑一张系统卡往下钻。
> 想看到哪了（进度）→ 看 `00-进度总览.md`（全景）· `00-当前进度.md`（此刻）。

---

## 〇、先记住两条规则（串行 / 并行）

- **箭头（→）= 串行**：左边没做完，右边做不了，必须排队。
- **没箭头 = 并行**：两个系统没谁等谁，可以两个人各拿一个背对背干。
- **接口冻结 = 把串行变并行**：本来 A→B 要等 A 做完，但只要把 A 和 B 之间那句"暗号"先定死（比如"这格能走吗"），B 就能拿假数据先干，不用等 A。

> 归类标准一句话：**拆到两块之间一句话暗号说得清为止，剩下的谁先谁后看箭头。**

## 一、理解层文件夹怎么分（5 个抽屉）

```text
01-理解层/
├─ 00-系统地图.md      ← 你在这
├─ 01-地图线/          ← 串行：资源 → 世界 → 图层 → 分块
├─ 02-玩法线/          ← 串行：输入 → 移动 → 玩家 → 相机
├─ 03-内容线/          ← 串行：区域触发 → 弹窗
├─ 04-独立件/          ← 随时并行：不依赖谁
└─ 05-旁支/            ← 世界盖好就能并行：挂世界上的装饰
```

- **01 / 02 / 03 是三条流水线**：每条线**内部**必须按编号排队（串行），**线跟线之间**可以并行。
- **04 独立件**：谁都不依赖，随便什么时候做，永远并行。
- **05 旁支**：都挂在"世界"上，所以等世界（02-世界与地图）盖好才能通电；盖好之后互相并行。

## 二、三条流水线（内部串行）

```text
地图线：  资源加载 ──▶ 世界与地图 ──▶ 图层与遮挡 ──▶ 地图分块
玩法线：  输入 ──▶ 移动与碰撞 ──▶ 玩家 ──▶ 相机
内容线：  区域触发 ──▶ 世界交互(弹窗)
```

**两条桥（跨线的接头）**：

| 桥 | 谁连谁 | 状态 |
|---|---|---|
| 能不能走 | 移动 ⇄ 地图 | ✅ 已定死（"这格能走吗" → true/false） |
| 相机范围 | 相机 → 地图分块 | ❌ 没定死（决定加载哪几块，【TBD】） |

> 这两条桥就是「能不能并行」的开关：**能不能走已冻死** → 玩法线和地图线可以同时干；**相机范围没冻死** → 相机和分块这俩得先碰头对暗号。

## 四、三大层（先分清哪块归哪）

```text
网站应用层（外壳）
  └─ 应用启动与页面 SYS-APP

虚拟世界层（游戏本体，15 个系统）
  ├─ 资源加载 SYS-ASSET
  ├─ 世界与地图 SYS-WORLD
  │    ├─ 地图分块 SYS-CHUNK
  │    └─ 图层与遮挡 SYS-LAYER
  ├─ 玩家 SYS-PLAYER
  ├─ 输入 SYS-INPUT
  ├─ 移动与碰撞 SYS-MOVE
  ├─ 相机 SYS-CAMERA
  ├─ NPC SYS-NPC
  ├─ 车辆与路线 SYS-ROUTE
  ├─ 区域触发 SYS-ZONE
  ├─ 世界交互(弹窗) SYS-INTERACT
```

## 五、优先级（先做哪个）

| 档 | 系统 | 为什么 |
|---|---|---|
| **P0（先做，8 个）** | 资源加载、世界与地图、地图分块、图层与遮挡、玩家、输入、移动与碰撞、相机 | 绕不过去的基础能力 |
| **P1（靠后，7 个）** | 应用启动、NPC、车辆与路线、区域触发、世界交互、游戏UI、实体生命周期 | 影响完整度，可后补 |
| **P2（最后，1 个）** | 动效与粒子 | 纯氛围，最后做 |

> 优先级（先做哪个）和串并行（能不能一起做）是**两回事**：P0 里也有并行（地图线和玩法线），P1 里也有串行（区域触发→弹窗）。

## 六、它们怎么接（一眼看懂协作关系）

```text
          [输入] ──方向──▶ [移动与碰撞] ──"能走吗"──▶ [地图/世界]
                              ▲
                              │ 位置
          [玩家] ─────────────┘
              │ 位置
              ▼
          [相机] ──相机范围──▶ [地图分块] ──放/撤块──▶ [世界与地图]
                                                          │
                            [图层与遮挡] [NPC] [车辆] [动效] 都挂在世界上面
              │
          [区域触发] ──触发──▶ [世界交互(弹窗)] ──展示──▶ [内容层]
```

**一句话总结**：输入 → 移动 → 碰撞（问地图）；玩家位置喂给相机和分块；分块决定加载哪几块、往世界里放；世界是地基，图层/NPC/车辆都挂它上面；区域触发接弹窗、弹窗展示内容。
