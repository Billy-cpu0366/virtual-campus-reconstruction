# 玩家（SYS-PLAYER）

> 📌 进度：🟡 懂一半 —— 精灵表还没拿到

## 它是什么

游戏里你操控的那个角色：长什么样、有什么动作、从哪出生、有哪些状态。

## 它管哪些事

- 玩家精灵（48×48）
- 8 方向移动动画（上 / 下 / 左 / 右，每个方向多帧）
- 出生点（1088, 304）
- 换装（沙滩）、脚印池、传送特效、桥切换

## 走一遍

玩家出生在 (1088, 304) → 按方向键 / WASD / 摇杆 → 角色朝对应方向走、播放对应动画 → 走到沙滩自动换装 → 传送时播放粒子特效。

## 为什么这么设计

玩家是游戏的主体，动画和状态机是核心。原站玩家有"动态深度"（depth = 500 + y × 0.1），保证角色在建筑前后能正确遮挡。

## 跟谁接头

- 出 → 相机 / 移动：提供自己的位置
- 入 ← 输入：方向
- 入 ← 移动：碰撞结果（能不能走）

> 精确约定见 `../../02-暗号层/接头暗号表.md`

## 容易踩的坑

- **三输入归一化**：方向键、WASD、摇杆三种输入，要合成一个方向
- **动态深度**：depth 跟 y 坐标挂钩，保证遮挡正确
- 沙滩换装、传送特效这些细节，是"玩家状态机"的一部分

## 我要学什么

"**角色状态机**"（待机 / 行走 / 换装 / 传送），以及"**用 depth 做遮挡**"的小技巧。
