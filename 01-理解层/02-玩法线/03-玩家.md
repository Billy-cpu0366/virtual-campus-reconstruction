# 玩家（SYS-PLAYER）

> 📌 进度：📐 画好图纸 —— 出生点+深度+状态机+换装已定稿

## 它是什么

游戏里你操控的那个角色：从哪出生、长什么样、有什么动作状态。

## 它管哪些事

- 玩家精灵（48×48，8 方向 × 8 帧动画）
- 出生点（1088, 304）
- 动态深度（500 + y×0.1，越往下越靠前，遮挡正确）
- 动画状态机（走路 / 空闲小动作 / 坐下 / 换装 / 被怪抓）
- 沙滩换装（脱衣 / 穿衣动画，48×48 ↔ 64×64）

## 走一遍

玩家出生在 (1088, 304) → 开场动画结束后才听你操作 → 按方向走、播对应方向动画 → 30 秒不动就坐下（冒 Z）、8 秒不动就做小动作 → 走到沙滩自动换装 → 被怪物抓时变"被拎着"的贴图。

## 为什么这么设计

- 动态深度（500 + y×0.1）：角色在建筑前后能正确遮挡。
- 空闲小动作 + 坐下：让角色"活"起来，不呆板。

## 跟谁接口

- 出 → 相机 / 移动：提供自己的位置
- 入 ← 输入：方向
- 入 ← 移动：碰撞结果（能不能走）

> 精确约定见 `../../02-接口层/API契约表.md`

## 容易踩的坑

- **三输入归一化**（归输入系统）：方向键、WASD、摇杆要合成一个方向。
- **动态深度**：depth 跟 y 坐标挂钩，别写成固定值。
- **换装会卡住**：脱/穿衣服的动画如果没加载，状态会卡住（原站没兜底）。

## 我要学什么

"**角色状态机**"（待机 / 行走 / 换装），以及"**用 depth 做遮挡**"的小技巧。
