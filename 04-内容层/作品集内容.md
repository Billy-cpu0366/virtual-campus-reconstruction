# 作品集内容（Phase 1 复刻的"剧本"）

> 复刻的"内容层"不是剧情，是 **Peter Oravec 的个人作品集内容**。系统层管"怎么动"，这里管"展示什么"。

---

## 一、10 个模态窗口内容

| 模态 | 展示什么 |
|---|---|
| Technologies | 4 个核心技术卡（Angular / Node.js / Express.js / JavaScript）+ "Other technologies" 列表 |
| About Me | 头像照片 + 姓名 + 职位 + LinkedIn 链接 + 3 段自我介绍 |
| CV | 5 家公司时间线（GAMO → SCR → Kremsa Digital → Bethereum → VUB Bank），每家可展开项目列表 |
| Projects | 3 个个人项目（eUTxO.org / Angular.sk / 旧版作品集） |
| Contact | LinkedIn + Email |
| Memo Cards ×6 | 可收集卡片，全息 / 反光 / 闪光 / 棱镜特效，支持 ← → 导航 |
| Big Map | 全局地图，CRT / VHS 老电视效果，含图例 + 玩家位置脉冲 |
| Under the Hood | 6 标签页：Architecture / Phaser.js / Chunk System / NPC System / Tiled Editor / Optimization |

---

## 二、交互点分布

- **信息点**：Technologies、About Me、CV、Projects、Contact、Under the Hood
- **Memo 点**：6 张卡片的隐藏位置
- **地图 marker**：11 个（sunburn×5 + vortex×6）
