## 执行层的逻辑（人话版）

AI 怎么逆向一个系统，走 7 步（详见旧仓库 `AGENTS.md` 和流程速查）：

```text
发现 → 登记 → 调查+设计 → 定验证 → 存未知 → 你授权 → 写代码+验证
```

最要命的一条：**第 6 步必须你签字**，没签字不许写代码，每次只授权很小一步。
